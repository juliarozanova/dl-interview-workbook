## Optimising what you can only sample

In reinforcement learning, a **policy** $\pi_\theta(a\mid s)$ chooses actions and the environment responds with rewards. We want to maximise the expected return,
$$J(\theta) = \mathbb E_{\tau\sim p_\theta}\big[R(\tau)\big],$$
but the trajectory $\tau$ comes from **sampling** actions and from **unknown dynamics**. Neither can be backpropagated through. The **policy gradient theorem** turns $\nabla_\theta J$ into an expectation we *can* estimate from samples:
$$\nabla_\theta J = \mathbb E_\tau\Big[\textstyle\sum_t \nabla_\theta\log\pi_\theta(a_t\mid s_t)\,\hat R_t\Big].$$

The same **score-function (REINFORCE) estimator** turns up beyond RL: for discrete latent variables, for hard attention, and in RLHF for language models (PPO and GRPO are refinements of it).

# The policy gradient theorem

:::prereq
- **The log-derivative trick.** $\nabla_\theta\, p_\theta = p_\theta\,\nabla_\theta\log p_\theta$, because $\nabla\log p = \nabla p / p$.
- **The trajectory probability.** $p_\theta(\tau) = p(s_0)\prod_t \pi_\theta(a_t\mid s_t)\,P(s_{t+1}\mid s_t, a_t)$.
- **Normalisation.** $\sum_a \pi_\theta(a\mid s) = 1$ for every $\theta$.
:::

:::task
Derive $\nabla_\theta J = \mathbb E_\tau\big[R(\tau)\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)\big]$. Show that the environment's dynamics drop out, that subtracting a **baseline** $b(s)$ leaves the gradient unbiased, and why each action only needs the **reward-to-go**. Practise it out loud: this is one of your five priority derivations.
:::

:::scaffold
Write `∇` (or `\nabla`) and `log`.

**1. The log-derivative trick.** $\nabla_\theta J = \int R(\tau)\,\nabla_\theta p_\theta(\tau)\,d\tau$, and $\nabla_\theta p_\theta(\tau) = p_\theta(\tau)\,\cdot$ {{ ∇log p(τ) | \nabla\log p(\tau) | ∇_θ log p_θ(τ) | \nabla_\theta \log p_\theta(\tau) | re:(∇|\\nabla).*log ? Since $\nabla\log p = \nabla p/p$, multiply both sides by $p$. That turns an integral of a gradient back into an **expectation** under $p_\theta$. }}

**2. The dynamics drop out.** $\log p_\theta(\tau) = \log p(s_0) + \sum_t\big[\log\pi_\theta(a_t\mid s_t) + \log P(s_{t+1}\mid s_t,a_t)\big]$. The gradient of the dynamics terms is {{ 0 | zero ? The environment doesn't depend on $\theta$. Only the policy terms survive, which is why model-free RL is possible. }}

**3. The baseline is free.** $\mathbb E_{a\sim\pi}\big[\nabla_\theta\log\pi_\theta(a\mid s)\big] = \sum_a \nabla_\theta\pi_\theta(a\mid s) = \nabla_\theta$ {{ 1 | Σ_a π(a|s) | \sum_a \pi(a|s) ? The probabilities sum to one for every $\theta$, and the gradient of a constant vanishes. }} $= 0$, so subtracting any $b(s)$ from the return leaves the expected gradient unchanged.

**4. Reward-to-go.** By causality, the action at time $t$ can only affect rewards at times $t' \ge$ {{ t | t' = t ? An action can't change rewards that were received before it was taken. Those terms average to zero, like a baseline, and only add variance. }}
:::

:::derivation
**Differentiate under the integral.**
$$\nabla_\theta J = \nabla_\theta\int p_\theta(\tau)R(\tau)\,d\tau = \int \nabla_\theta p_\theta(\tau)\,R(\tau)\,d\tau .$$
$R$ doesn't depend on $\theta$ directly, only through which trajectories are likely.

---step---

**The log-derivative trick.** Substitute $\nabla p = p\,\nabla\log p$:
$$\nabla_\theta J = \int p_\theta(\tau)\,\nabla_\theta\log p_\theta(\tau)\,R(\tau)\,d\tau = \mathbb E_{\tau}\big[R(\tau)\,\nabla_\theta\log p_\theta(\tau)\big].$$
It's an expectation again, so sample trajectories and average.

---step---

**Factor the trajectory.** The initial state and the dynamics don't depend on $\theta$:
$$\nabla_\theta\log p_\theta(\tau) = \sum_t \nabla_\theta\log\pi_\theta(a_t\mid s_t).$$
You never need a model of the environment.

---step---

**Reduce variance without bias.**

- **Baseline.** $\mathbb E_{a\sim\pi}[\nabla\log\pi(a\mid s)\,b(s)] = b(s)\,\nabla\sum_a\pi(a\mid s) = 0$, so use $R - b(s)$. The value function $V(s)$ is the classic choice, and $R - V$ is the **advantage**.
- **Reward-to-go.** Rewards before time $t$ are independent of $a_t$, so drop them: $\hat R_t = \sum_{t'\ge t} r_{t'}$.

$$\nabla_\theta J = \mathbb E\Big[\textstyle\sum_t \nabla_\theta\log\pi_\theta(a_t\mid s_t)\,\big(\hat R_t - b(s_t)\big)\Big].$$

---step---

**Where it leads.** Actor–critic methods learn $b = V_\phi$. PPO clips the policy ratio to keep updates small. GRPO, used for LLM reasoning, uses the group-mean reward as the baseline. All of them are this gradient, made lower-variance and more stable.
:::

:::solution{lang=python}
import numpy as np

def softmax(z):
    e = np.exp(z - z.max())
    return e / e.sum()

def exact_grad(theta, means):
    p = softmax(theta)
    return p * (means - p @ means)

def reinforce_estimate(theta, means, n, rng, baseline=0.0):
    p = softmax(theta)
    a = rng.choice(len(p), size=n, p=p)
    r = means[a] + rng.normal(size=n)
    score = np.eye(len(p))[a] - p
    return ((r - baseline)[:, None] * score).mean(axis=0)
:::

:::explain
[L7-9] **The exact gradient**, for a softmax bandit with $J = \sum_a \pi_a m_a$. Differentiating directly gives $\pi_a(m_a - \bar m)$. Arms better than average get pushed up.

[L11-16] **The REINFORCE estimate.** For a softmax policy, $\nabla_\theta\log\pi_a = e_a - \pi$, the same "one-hot minus probabilities" pattern as Chapter 04. The tests check that the sample average converges to the exact gradient, with or without a baseline.
:::

:::tests{lang=python}
import numpy as np

def test_reinforce_matches_exact_gradient():
    theta, means = np.array([0.2, -0.1, 0.4, 0.0]), np.array([1.0, 2.0, 0.5, 1.5])
    est = reinforce_estimate(theta, means, 400000, np.random.default_rng(0))
    assert np.allclose(est, exact_grad(theta, means), atol=0.01)

def test_baseline_keeps_it_unbiased():
    theta, means = np.array([0.2, -0.1, 0.4, 0.0]), np.array([1.0, 2.0, 0.5, 1.5])
    est = reinforce_estimate(theta, means, 400000, np.random.default_rng(1), baseline=1.2)
    assert np.allclose(est, exact_grad(theta, means), atol=0.01)
:::

# REINFORCE on a multi-armed bandit

:::prereq
A $K$-armed bandit has one state. Arm $a$ pays $m_a + \text{noise}$.

- **Policy:** $\pi = \mathrm{softmax}(\theta)$.
- **One REINFORCE step:** sample $a\sim\pi$, observe $r$, then $\theta \leftarrow \theta + \eta\,(r - b)\,(e_a - \pi)$.
- **A running baseline:** $b \leftarrow b + \beta\,(r - b)$, an exponential average of recent rewards.

:::solution{lang=python}
import numpy as np

def softmax(z):
    e = np.exp(z - z.max())
    return e / e.sum()

def reinforce_bandit(means, steps=2000, lr=0.1, baseline=True, seed=0):
    rng = np.random.default_rng(seed)
    theta, b = np.zeros(len(means)), 0.0
    for _ in range(steps):
        p = softmax(theta)
        a = rng.choice(len(means), p=p)
        r = means[a] + rng.normal()
        score = np.eye(len(p))[a] - p
        theta = theta + lr * (r - b if baseline else r) * score
        if baseline:
            b = b + 0.05 * (r - b)
    return softmax(theta)
:::

:::explain
[L12-13] **Act, then observe.** We never differentiate through `rng.choice` or the reward. That's the whole point of the score-function estimator.

[L14-15] **Ascend.** We maximise return, so it's `+`. With a baseline, only rewards *better than usual* push an action's probability up, and worse-than-usual ones push it down. Without one, every positive reward reinforces whatever was chosen, which is much noisier (next exercise).

[L16-17] **Track the baseline.** A running average is the simplest baseline. Actor–critic methods replace it with a learned $V(s)$. The tests check that the policy concentrates on the best arm, with over 90% probability, across seeds.
:::

:::tests{lang=python}
import numpy as np

def test_finds_the_best_arm():
    means = np.array([1.0, 1.5, 2.0, 0.5])
    for seed in range(3):
        p = reinforce_bandit(means, seed=seed)
        assert p.shape == (4,) and np.isclose(p.sum(), 1) and p[2] > 0.9

def test_without_baseline_still_runs():
    p = reinforce_bandit(np.array([0.0, 1.0]), steps=500, baseline=False)
    assert np.isclose(p.sum(), 1)

::::exercise{id=baseline-variance-predict type=predict difficulty=2 time=6 runtime=browser udl="§19.5" tags="rl,policy-gradient-derivation"}
# Add 10 to every reward

:::task
On a bandit, you **add 10 to every reward**. That changes nothing about which arm is best. Using REINFORCE **without a baseline**, what happens to the policy-gradient estimator?
:::

:::choices
- [ ] Nothing: a constant shift can't change the gradient
- [ ] It becomes biased towards the arm chosen most often
- [x] Its expectation is unchanged, but its variance grows enormously (about 100×)
- [ ] It becomes exactly zero
:::

:::experiment{lang=python}
import numpy as np

def softmax(z):
    e = np.exp(z - z.max())
    return e / e.sum()

theta, means = np.array([0.2, 0.1, 0.0, -0.3]), np.array([1.0, 1.5, 2.0, 0.5])
p = softmax(theta)

def samples(offset, baseline, n=20000, seed=0):
    rng = np.random.default_rng(seed)
    m = means + offset
    a = rng.choice(4, size=n, p=p)
    r = m[a] + rng.normal(size=n)
    b = p @ m if baseline else 0.0
    return (r - b)[:, None] * (np.eye(4)[a] - p)

def expected(offset, baseline):
    m = means + offset
    b = p @ m if baseline else 0.0
    return sum(p[a] * (m[a] - b) * (np.eye(4)[a] - p) for a in range(4))

for offset in (0, 10):
    for baseline in (False, True):
        g = samples(offset, baseline)
        print(f"offset {offset:2d}, baseline {str(baseline):5s}:  E[grad] {np.round(expected(offset, baseline), 3)}   total variance {g.var(axis=0).sum():8.2f}")
:::

:::tests{lang=python}
import numpy as np

def test_expectation_is_unchanged_by_the_offset():
    assert np.allclose(expected(0, False), expected(10, False))
    assert np.allclose(expected(10, False), expected(10, True))

def test_variance_explodes_without_a_baseline():
    v_plain = samples(10, False).var(axis=0).sum()
    v_base = samples(10, True).var(axis=0).sum()
    assert v_plain > 50 * v_base
:::

:::explain
**Unbiased, either way.** The offset adds $10\,\mathbb E[\nabla\log\pi] = 10 \cdot 0 = 0$ to the expected gradient. That's the baseline argument from Exercise 22.1, run backwards: a constant you *add* is exactly as harmless as a constant you subtract, *in expectation*.

**The variance is a different story.** Each sample is $(r)\,(e_a - \pi)$. With $r \approx 11$ instead of $1$, every sample is multiplied by about 11, so the variance grows by about $11^2 \approx 100$. Every action now looks "good" and gets reinforced, and only small differences between huge numbers carry the signal. Learning slows to a crawl, or needs a far smaller learning rate.

**The fix** is the baseline. Subtracting $b \approx \mathbb E[r]$ centres the returns, which removes the offset's effect entirely. That's why every practical policy-gradient method uses advantages, $\hat R - V(s)$, and why GRPO normalises rewards within each group of samples.
:::

:::interview
- Is REINFORCE invariant to adding a constant to the rewards? *(In expectation, yes. In variance, no.)*
- What baseline minimises variance? *(Roughly the expected return, $V(s)$. The exact optimum weights by $\|\nabla\log\pi\|^2$.)*
- Why do PPO implementations normalise advantages per batch?
:::
